# Changelog

## 0.3.1

- First public release on the VS Code Marketplace and Open VSX.
- Separate English and Khmer fonts and sizes for Claude Code chat and the terminal.
- Styles for every chat item: text, headings 1–6, bold, italic, crossed-out, link, inline code, code block, list, bullet, quote, table header, table cell and divider.
- Settings page with live preview.
- Styles are restored automatically after Claude Code updates.
- `Claude Style: Remove My Styles` restores your previous settings.
